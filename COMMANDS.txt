=============================================================================
TCP TRAFFIC CLASSIFICATION - QUICK COMMAND REFERENCE
=============================================================================

INSTALLATION
------------
pip install -r requirements.txt


QUICK START (Recommended for first run)
----------------------------------------
python run_solution.py --mode auto

# Or explicitly use quick mode
python run_solution.py --mode quick


TESTING ON SAMPLE
-----------------
# Test with 10,000 samples (fast, ~5-10 minutes)
python run_solution.py --mode full --sample-size 10000 --no-lifestream


FULL PIPELINE OPTIONS
---------------------
# Balanced (recommended): TSFEL + no Lifestream (~2-4 hours)
python run_solution.py --mode full --no-lifestream

# Maximum quality: TSFEL + Lifestream (~4-6 hours)
python run_solution.py --mode full

# Fastest full: no TSFEL, no Lifestream (~1-2 hours)
python run_solution.py --mode full --no-tsfel --no-lifestream

# Maximum features: all TSFEL domains + Transformer (~6-10 hours)
python run_solution.py --mode full --tsfel-domain all --lifestream-encoder transformer


DIRECT SCRIPT EXECUTION
------------------------
# Quick baseline
python quick_train.py

# Full pipeline with custom parameters
python main_pipeline.py --train train.csv --test test.csv --output submission.csv

# With specific options
python main_pipeline.py \
    --sample-size 50000 \
    --no-lifestream \
    --tsfel-domain statistical \
    --cv-folds 3


DATA ANALYSIS
-------------
python analyze_data.py


TROUBLESHOOTING
---------------
# Memory issues - reduce chunk size
python main_pipeline.py --chunk-size 20000

# Long training - use fewer CV folds
python main_pipeline.py --cv-folds 3

# CUDA errors - disable Lifestream
python run_solution.py --mode full --no-lifestream


CHECKING RESULTS
----------------
# Windows PowerShell
Get-Content submission.csv -TotalCount 10

# Linux/Mac
head submission.csv

# Python
python -c "import pandas as pd; print(pd.read_csv('submission.csv').head())"


RECOMMENDED WORKFLOW
--------------------
# 1. Analyze data (optional)
python analyze_data.py

# 2. Quick test on sample
python run_solution.py --mode full --sample-size 10000 --no-lifestream

# 3. Full training
python run_solution.py --mode full --no-lifestream

# 4. Check submission
Get-Content submission.csv -TotalCount 10

# 5. Submit to Kaggle!


PARAMETER REFERENCE
-------------------
--mode {quick,full,auto}           Solution mode
--sample-size N                    Use N samples for training
--no-tsfel                         Disable TSFEL features
--no-lifestream                    Disable Lifestream embeddings
--tsfel-domain {statistical,temporal,spectral,all}
--lifestream-encoder {rnn,transformer}
--cv-folds N                       Number of CV folds (default: 5)
--chunk-size N                     Chunk size for large files (default: 50000)


TIME ESTIMATES
--------------
Quick baseline:                    30-60 minutes
Full (no Lifestream):             2-4 hours
Full (with Lifestream RNN):       4-6 hours
Full (with Lifestream Transformer): 6-10 hours
Sample test (10k rows):           5-10 minutes


EXPECTED PERFORMANCE
--------------------
Quick baseline:                    95-97% accuracy, 0.15-0.20 log loss
Full (no Lifestream):             97-98% accuracy, 0.10-0.15 log loss
Full (with Lifestream):           98-99% accuracy, 0.08-0.12 log loss
